إعداد المزامنة السحابية الفورية (Firebase Sync)

إزاي تجيب رابط قاعدة البيانات في دقيقة واحدة؟

1. افتح موقع Firebase Console واعمل مشروع جديد (Create a project).

2. من القائمة الجانبية اختار Build ثم Realtime Database واضغط Create Database.

3. اختار Start in test mode واضغط Enable.

4. انسخ الرابط اللي هيظهرلك فوق في الصفحة (بيكون آخره firebaseio.com أو firebasedatabase.app) أو انسخ كود firebaseConfig كله والصقه هنا بالأسفل!
